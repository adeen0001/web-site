THE PERFECT DAY — setup
========================

1. Extract zip
2. Open folder in VS Code
3. Right click index.html > Open with Live Server

No build step, no npm install — just HTML, CSS and vanilla JS.
(You can also just double-click index.html to open it straight in
a browser, but Live Server behaves a little better with relative paths.)

Folder structure:
perfect-day-website/
  index.html
  css/style.css
  js/script.js
  assets/favicon.png
  assets/corkboard-bg.jpg

Notes you jot down on the corkboard save to localStorage under the
key "perfectDayNotes", so they'll still be there next time you open
the page in the same browser. Clearing browser data will wipe them.

Enjoy :)
